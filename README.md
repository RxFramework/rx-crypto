# rx-crypto

**Cryptocurrency** — part of the [RX Framework](https://docs.rxcore.org) for FiveM.

## Description

Provides the logic for handling cryptocurrency aka qbit

## Requirements

- **rx-core** — RX Framework core
- **oxmysql**

## Configuration

Edit `config.lua` (and locale files if present) in this resource folder.

## QBCore / Qbox scripts

Third-party QBCore or Qbox resources are supported via the compatibility bridges in **rx-core** (`bridge/qbcore`, `bridge/qbox`). Native RX resources use **RXCore** and `@rx-core` imports.
